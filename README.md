# TensorCompile

**TensorCompile** — это легковесный AOT компилятор для нейронных сетей, построенный на базе инфраструктуры **LLVM** и **MLIR**. 

Проект принимает на вход модели в формате **ONNX**, строит внутреннее представление вычислительного графа, транслирует его в многоуровневое представление (MLIR), применяет понижение абстракции (Lowering) и генерирует нативный ассемблерный код для целевой архитектуры (x86-64).

## Особенности

- **ONNX Frontend:** Парсинг `.onnx` файлов с использованием Protobuf. Извлечение информации об узлах, входах/выходах и атрибутах (kernel shape, strides и т.д.).
- **IR & Graph Representation:** Построение ориентированного вычислительного графа с возможностью экспорта в формат GraphViz (`.dot`).
- **MLIR Backend:** Кодогенерация в диалекты MLIR (`func`, `arith`).
- **Lowering & LLVM IR:** Оптимизация и понижение уровня абстракции графа нейросети до LLVM IR.
- **Native Code Generation:** AOT-компиляция в нативный машинный код (`.s` ассемблер) .
- **Поддерживаемые операции (на архитектурном уровне):** `Add`, `Mul`, `Relu`, `Conv`, `MatMul`, `Gemm`, `Reshape`.

##  Зависимости

Для сборки проекта требуются:
- **C++23** совместимый компилятор (например, GCC 13+)
- **CMake** >= 3.28
- **LLVM & MLIR 17** (пакеты `llvm-17-dev`, `libmlir-17-dev`)
- **Protobuf** (`libprotobuf-dev`)
- **Google Test** (`libgtest-dev` для юнит-тестов)
- **Python 3** + `torch`, `onnx`, `onnxscript` (для скрипта генерации тестовых моделей)
- **GraphViz** (опционально, для отрисовки графа)

## Сборка проекта

Проект использует CMake. Для конфигурации и сборки выполните следующие команды:

```bash
# Очистка старого кэша
rm -rf build/

# Конфигурация проекта 
cmake -B build -G Ninja \
    -DMLIR_DIR=/usr/lib/llvm-17/lib/cmake/mlir \
    -DLLVM_DIR=/usr/lib/llvm-17/lib/cmake/llvm

# Сборка
cmake --build build
```

## Использование

### 1. Генерация тестовой ONNX-модели
В проекте есть Python-скрипт `generate_onnx.py`, который создает простую нейросеть средствами PyTorch и экспортирует её в ONNX.

```bash
# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install torch onnx onnxscript

# Генерация модели (сохранится в data/full_model.onnx)
python3 generate_onnx.py
```

### 2. Запуск компилятора
Передайте путь к `.onnx` файлу в исполняемый файл компилятора:

```bash
./build/etc_compiler data/full_model.onnx -dump-mlir -dot=graph.dot
```

**Флаги:**
- `-dump-mlir`: Выводит в консоль код MLIR до и после понижения в диалект LLVM.
- `-dot=<filename.dot>`: Сохраняет вычислительный граф в формате GraphViz.

### 3. Результаты работы
В результате успешной компиляции:
1. В консоль будет выведен MLIR и LLVM IR код.
2. В корне проекта появится файл **`output_asm.s`** — сгенерированный ассемблерный код процессора.
3. Появится файл **`graph.dot`**, который можно превратить в PNG-изображение графа сети с помощью команды:
   ```bash
   dot -Tpng graph.dot -o graph.png
   ```

## Тестирование

Проект покрыт юнит-тестами с использованием Google Test. Тесты проверяют структуру графа, работу ONNX парсера и корректность генерации MLIR контекста.

Запуск тестов:

```bash
./build/tests/compiler_ut
```

##  Структура проекта

- `/src` — исходный код компилятора (Frontend, MLIR Codegen, LLVM Backend).
- `/include` — заголовочные файлы (`.hpp`).
- `/tests` — юнит-тесты GTest.
- `/data` — директория для хранения `.onnx` моделей.
- `generate_onnx.py` — утилита для создания тестовых нейросетей.
